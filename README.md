A tiny deterministic program that writes one 148-character line of quiet, earned pride — "After three failed harvests, she knelt in the dry field at dusk, pressed the first green shoot between her fingers, and finally let herself believe." — to `/output/entry.txt` for make.fun's "One Line of Earned Pride" bounty. Deterministic, Node stdlib only, no network.

## Run it

```sh
node main.ts
```
